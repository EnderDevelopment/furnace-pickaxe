# Furnace Pickaxe Minecraft Plugin

Furnace Pickaxe is a Minecraft plugin for Paper that adds a custom furnace pickaxe. This Minecraft plugin automatically smelts mining drops from smeltable blocks, provides a shaped crafting recipe using furnaces and sticks, and includes Efficiency II.

## Install

1. Build the plugin with Maven using Java 21.
2. Copy the generated `plugin.jar` file into your server's `plugins` folder.
3. Start or restart a Paper 1.21 server.
4. Confirm that FurnacePickaxe is enabled in the server console.

## Use

1. Craft the Furnace Pickaxe with this recipe:

   ```
   Furnace Furnace Furnace
   Empty   Stick   Empty
   Empty   Stick   Empty
   ```

2. Hold the Furnace Pickaxe in your main hand.
3. Mine blocks with drops that have a vanilla furnace recipe, such as stone or ores.
4. The plugin automatically gives you the smelted result.
5. Drops that cannot be smelted are delivered unchanged.
6. If your inventory is full, excess items are dropped naturally at the mined block's location.
